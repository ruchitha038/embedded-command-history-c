A menu-driven Embedded Command History System implemented in C using stack operations such as push, pop, peek, display, and search.
# Embedded Command History System in C

The Embedded Command History System is a simple C program that uses a stack to store and manage commands.

## Theory

A stack is a linear data structure that follows the Last In, First Out (LIFO) principle. The last command added to the stack is the first command removed. This project demonstrates the use of stack operations in C programming.

## Files

- `command_history.c` – Implements command history operations.
- `embedded_stack.c` – Demonstrates basic stack operations.

## Conclusion

This project helps in understanding stack operations and their applications in command history management using C programming.
